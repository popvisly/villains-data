# Resilience Index Assessment Skill

This skill allows the agent to calculate the "Resilience Index" by identifying where human discretion is the primary value driver.

## Context

In the AI economy, "slop" (generic, automated output) is commoditized. "Judgment" (discretionary choices under constraint) is the moat. This skill defines the criteria for that distinction.

## Judgment Criteria

### 1. Routine (Automation Candidates)

- Rules-based logic.
- Predictable inputs/outputs.
- Low-stakes physical or financial accountability.
- High volume, low variety.

### 2. Strategic (Judgment Moats)

- Requires real-time human negotiation or empathy.
- High-stakes accountability (regulatory, board-level, or life-safety).
- Complex troubleshooting where models lack current context.
- Strategic constraint mapping (balancing technical debt vs. speed).

## Triage Protocol

1. **Identify the Core Decision**: What is the singular choice being made?
2. **Map the Constraints**: What are the non-negotiables?
3. **Pressure Test**: What happens if the primary model/system fails here?
4. **Capture the Proof**: Formulate the decision as an artifact (Decision Log, Risk Register).

## Usage

Use this skill when analyzing tasks for the "Resilience Index" or generating "Proof Portfolios."
